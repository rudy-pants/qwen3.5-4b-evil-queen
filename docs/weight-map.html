Plate 0 · the two terms

SiLU and gate_proj

SiLU(x) = x · sigmoid(x)

SiLU (also called Swish) is the nonlinearity in each MLP. For large positive inputs it passes x through almost unchanged. For large negative inputs it goes to 0. Near zero it bends smoothly and dips slightly below zero, bottoming out at about −0.28 when x ≈ −1.28. Think of it as a smooth ReLU that lets small negative values through.

SiLU ReLU, for comparison

gate_proj: the "how open" signal

Qwen's MLP is a SwiGLU block. The normalized residual vector x (2560 numbers) goes through two separate linear layers that each expand it to 9216 numbers:

gate = gate_proj(x) # [9216 × 2560] matrix up = up_proj(x) # [9216 × 2560] matrix h = SiLU(gate) * up # 9216 "neurons" out = down_proj(h) # [2560 × 9216], back to 2560

up carries the content. gate, after SiLU, decides how much of each of the 9216 content values gets through: near 0 blocks it, a large value amplifies it. Neuron n's activation is h[n].

So one neuron is really three slices of weights: row n of gate_proj, row n of up_proj, and column n of down_proj. The first two decide when it fires. The third decides what it writes back into the residual stream.

Plate 3 · one neuron

Where the steering lands

The hook adds Δ to one entry of h, the input of down_proj, at every token. Because down_proj is linear, that adds Δ · W_down[:, n] to the layer's output. The gate and up rows are drawn for context: they set the neuron's normal activation, but steering ignores them.

Plugging into the recipe
